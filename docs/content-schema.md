# Формат квеста

Один квест = одна папка `quests/<slug>/`:

| файл | что |
|---|---|
| `quest.json` | всё содержимое игры (схема — [schema/quest.schema.json](../schema/quest.schema.json)) |
| `pictos/*.svg` | свои пиктограммы квеста (перекрывают и дополняют общую библиотеку `assets/pictos/`) |
| `_shots/` | снимки `tools/shot.mjs` |
| `NOTES.md` | заметки автора: сюжет, разгадка, сверка (спойлеры — сюда, не в игру) |

Сборка кладёт игру в `games/<slug>/` — её не правят руками.

## Разметка текста

Во всех репликах, табличках, просьбах и тексте главной задачи:

- `[[id|форма]]` — целевое слово (id из `words`) в нужной форме: `[[mikros|μικρή]]`. Без `|форма` подставится словарная форма.
- остальной греческий — обычный текст; **каждая** его словоформа обязана быть в `gloss` (`"είναι": ["είμαι", "есть, является"]`) или в `names` (имена и названия, ключ в нижнем регистре). Иначе validate не пропустит: у игрока на каждом греческом слове должен быть тултип.

## Разделы

### meta
`slug` (= имя папки), `saveKey` (уникальный ключ сохранения; им же шифруются ответы в сборке), `title`, `titleGr`, `titleRu`, `kicker`, `cover` (текст обложки), `mysteryBtn` (короткое имя главной задачи: «Песня», «Надпись», «Рецепт», «Объявление»), `lockedText`, `theme` (CSS-переменные, необязательно).

### intro
Завязка по-русски: `title`, `paragraphs[]` (HTML можно), `button` (к тексту задачи), `enter` (в мир). После вступления игрок видит текст главной задачи — это и есть «зачем».

### words — целевые слова
```json
"mikros": { "gr": "μικρός, -ή, -ό", "ru": "маленький", "alt": ["маленькая","небольшой"], "pos": "adj", "picto": "small", "claimKind": "size" }
```
- `gr` — как в списке ученика; `ru` — основной перевод (его покажет игра после разгадки); `alt` — ещё принимаемые ответы.
- `picto` — пиктограмма для страницы дневника и повторения: `assets/pictos/<id>.svg` (общая библиотека) или `quests/<slug>/pictos/<id>.svg`. Новые пиктограммы — SVG `viewBox="0 0 100 100"`, тёмный контур `#2b2a33` 3px, плоские цвета (смотри существующие).
- `claimKind` — слово, которое проверяется глазами (`size` большой/маленький, `price` дорогой/дешёвый, `near` близко/далеко, `place` здесь/там, `color`, `count`, `time`). Каждая фраза с таким словом обязана иметь утверждение в `claims` — см. [consistency.md](consistency.md).

### pages — страницы дневника
Группы по 3–5 слов, каждое слово ровно на одной странице. Страница открывается, когда игрок встретил все её слова; засчитывается, когда каждое слово лежит на своей картинке — перевод тогда вписывается сам. Группируйте по смыслу («Еда», «Где и когда», «Какое?»), чтобы картинки на странице подсказывали друг друга.

### world — мир как граф зон
- `zones[]` — **открытые** зоны (`kind: "outdoor"`: площадь, рынок, пристань, двор, поляна, перрон) и **интерьеры** (`kind: "interior"`: комнаты, лавки, каюта, вокзал). Открытая зона: `center` [x,z], `radius` или `rect` [w,d], `ground` (paving, cobble, street, grass, sand, dirt, planks, snow, stone, tiles, wood, carpet, none), `border` (ограда с калиткой: fence/hedge/wall, `gate` — угол), `lock` (условие открытия), `spawn`, `props[]`. Интерьер: `size` [w,d], `wall`, `floor`, `areas[]` (части комнаты: зал/кухня — для утверждений), `props[]`; дверь в него — у здания-предмета (`door.to`).
- Вложенные зоны можно: маленькая площадь внутри большой зоны квартала. Шапка показывает самую маленькую зону под героем; `nav: false` — не показывать зону в нижнем меню.
- `paths[]` — дорожки между точками/зонами; `water[]` — вода (прямоугольник/круг; не пройти, кроме мостков `p: "pier"`); `env` — время суток, цвет земли, туман, погода (rain/snow), фон (`backdrop`: city, hills, mountains, forest, sea), перекраска наборов (`recolor`).
- `layout` — если у открытой зоны нет `center`, раскладка сделает её сама (`ring`, `line`, `grid`). `free` — все центры заданы вручную.
- Оси: x — восток, z — юг, `rot` в радианах вокруг вертикали; фасад здания и лицевая сторона таблички смотрят на +z до поворота.
- **Камера локации** — `zone.camera: {yaw, pitch, d}`: ракурс постоянный, игрок его не крутит. `yaw` — откуда смотрит камера (0 — с юга на север, π — с севера на юг, π/2 — с востока на запад), `pitch` — наклон (0.62 обычно, 0.85 интерьер), `d` — дистанция при обычном виде (по умолчанию — самый дальний, `world.zoomMax`, 19; колесо приближает). Без `camera` — со спины героя в точке `spawn` (у интерьера — от входа). Между локациями (зоны с `nav: false` и `camera: "free"`) камера свободная: плавно поворачивается туда, куда идёт герой. Ставьте жителей, таблички и входы так, чтобы их было видно с ракурса своей локации. **Выход из здания** всегда с фиксированной камерой: в открытой локации — её ракурс, на дороге (свободная камера) — снаружи лицом к фасаду (`door.camera` переопределяет), пока герой не отойдёт от двери на 5 м.

### props — предметы
`m` — модель из `assets/catalog.json` (`kit/name`) с `h`/`w`/`s` (высота/ширина/масштаб в метрах). Или `p` — процедурный предмет движка:

| p | что | ключи |
|---|---|---|
| `building` | здание: модель `m` (с `h`/`w`) **или** процедурный дом без `m` — `size` [w,h,d], `color` стен, `roof`, `trim` (ставни, дверь) | `door: {to}`, `deco: [portico, kitchen-annex, awning, pad, nameplate]` |
| `boat` | лодка: корпус цвета `color`, длина `len`, `mast`, `stripe` (кромка); на воде покачивается, `float:false` — лежит на берегу | `len`, `color`, `float`, `y` |
| `pile` | горка фруктов/овощей в ящике цвета `color` | `n`, `r`, `size`, `crate:false` |
| `tree` | дерево из `m` с плодами | `fruit` (цвет), `seed` |
| `lamp` | фонарь (горит вечером/ночью) | `light` |
| `table` | столик кафе со стульями | `food: [[model, dx, dz, h]]` |
| `stall`, `kiosk`, `crates`, `fountain`, `column`, `violin`, `dog`, `cat`, `steam` | готовые формы | `color`, `walk` (собака бегает кругом), `r` |
| `pier` | мостки над водой | `rect` [w,d], `h` |
| `pricetag` | ценник с текстом | `text`, `value` (число для утверждений о цене), `size` |
| `box`, `cyl`, `ring`, `strip` | простые формы и дорожки | `size`, `r`, `r1/r2`, `color`, `ground` |
| `repeat` | ряд одинаковых | `n`, `step` [dx,dz], `item` |

Общие ключи: `id` (нужен, если на предмет ссылается утверждение), `at` [x,z] от центра зоны, `y`, `rot`, `col` (`"b"` коробка, число — радиус, `false` — не мешает ходить; по умолчанию — по габаритам), `on: [...]` (поставить сверху).

### npcs — жители
`name` (греч., добавить в `names`), `ru`, `gender` (f/m — голос и тон), `model` (`chars/character-…`), `zone`, `at`, `rot`, `hold` (предмет в правой руке), `looks` (2D-портрет: skin, hair, style: short/bob/bun/pony/long/chef/cap/hat/scarf/bald, top, bottom, dress, apron, mous, beard, glasses, old, dots, stripes, phones), `lines[]`: `{ t, req?: questId, until?: questId, reqMystery?: true, story?: true }`.

### signs — таблички
`title`, `style` (wood, plate, chalk, paper, cork, metal, stone), `lines[]`, `place: { zone, at, y, size [w,h], rot, mount }`. `mount`: post, posts, board, stand, signpost (каждая строка — своя стрелка), facade (на здании: у здания `deco: {p:"nameplate", sign:id}`), none. Подошёл к табличке — её текст всплывает крупно.

### quests — просьбы с пропусками
`{ id, npc, needPages[], after: {quests, pages, mystery}, pic, ask, parts[], thanks, toast?, finale? }`. `parts` — строки и пропуски `{ w: wordId, a: ["ответ", ...], hint?: "μικρός → το …" }`. Просьба видна, когда открыта зона жителя и выполнено `after`; решаема, когда разгаданы `needPages`. `pic` — id пиктограммы (широкая картинка) или список из 2–4 пиктограмм. `finale: true` — после неё финал.

### items, лавки и поручения: купи / отнеси / обменяй
- `items` — предметы для сумки и лавок: `{ "milo": { "gr": "[[milo|μήλο]]", "picto": "apple", "word": "milo" } }`. `gr` — имя по-гречески с разметкой: целевое слово (`[[id|форма]]`) или простое слово из `gloss` («καφές»). В сумке (панель слева) и в лавке имя с тултипом, как везде.
- **Торговец** — житель с `shop: [{ item, price, req?, until? }]` (цена за штуку, €) и, по желанию, `buys: [{ item, price }]` — что он берёт у игрока (по умолчанию — свои товары по той же цене: игра учебная, без штрафа). В его реплике кнопка «🛒 Купить / продать»:
  - **Купить** — список товаров только по-гречески с ценами и количеством; кнопка неактивна, если денег не хватает.
  - **Продать из сумки** — всё, что этот торговец берёт; «купил не то» всегда можно продать обратно и купить нужное, деньги не теряются.
  - Продать нельзя только то, что нужно для невыполненного поручения и больше нигде не продаётся (иначе тупик) — кнопка неактивна с пояснением.
  - Товары открытой лавки — место встречи слова (validate: источник `shop:<npc>:<i>`; считается и для постепенности).
- **Поручения** — элементы `quests[]` с `kind`:
  - `"errand"` — **купи**: `{ npc, give: { money }, want: { item, n }, to?, ask, remind?, thanks, reward? }`. Кнопка «Взять деньги» кладёт деньги в сумку; игрок покупает `want` у торговца и приносит `to` (по умолчанию тому, кто просил).
  - `"deliver"` — **отнеси**: `{ npc: A, give: { item, n }, to: B, reward?, ask, remind?, thanks }`, B ≠ A; `want` по умолчанию = `give`. Житель A даёт предмет, его нужно отдать B. Если у B есть `reward: { item }` — это **обмен**: отдал X, получил Y.
  - `"trade"` — **обменяй**: `{ npc: B, want: { item, n }, reward: { item, n } | { money }, ask, remind?, thanks }`. Брать заранее не нужно: принёс X — получил взамен.
  - **Цепочки** A → B → C: `deliver` (A даёт X, B берёт X и даёт Y) → `trade` у C (берёт Y, даёт Z или деньги). Связывай их `after: { quests: [...] }`.
  - Отдача всегда сама, при разговоре с нужным жителем, когда нужное есть в сумке; иначе он повторяет `remind` и мягко подсказывает (что купить не то — не беда, можно продать).
  - Любое поручение — полноценная волна: его id годится в `lock.quests`, `after.quests`, `req` реплик.
- **validate:**
  - предметы существуют и у них есть пиктограммы;
  - у `deliver` есть `give.item` и `to` ≠ `npc`;
  - у `trade` есть `reward`;
  - нужный предмет откуда-то берётся: его продают или его даёт другое поручение;
  - на «купи» денег хватает (иначе предупреждение);
  - прогон до финала проходит все поручения, на каждом «купи» с ошибкой игрока: купил не то → продал → купил нужное (деньги должны сойтись);
  - нужный дальше предмет, которого больше нигде не купить, продать нельзя (иначе тупик).

### mystery — глобальная задача
Текст на греческом, который игрок получает в начале и **переводит сам в конце**: надпись, объявление, рецепт, песня, табличка у входа, пророчество, правило игры. Это «то, что нужно перевести по финалу».
- `lines[]` — 4–8 строк из целевых слов (в каждой строке 2–4 целевых слова), `ru[]` — построчный перевод.
- `need` — когда открывается перевод (по умолчанию `{allPages:true}`), `question` — вопрос на понимание с вариантами (`answer` — индекс строкой), `reveal[]` — что открылось.
- Перевод проверяется по словам (нечётко, как в дневнике), строка засчитывается целиком и проявляет свой русский смысл.
- `place` — где в мире лежит предмет с этим текстом (необязательно; можно подойти и «рассмотреть»).

### finale
`zone`, `night`, `hero` [x,z,yaw], `cast: {npc: [x,z,yaw]}`, `camera: {at, d, yaw}`, `lines[]` ({who, t}), `epilogue: {title, paragraphs[] ({known}/{total} — сколько слов выучено), last}`. `trigger: "mystery"` — финал сразу после перевода; иначе — после просьбы с `finale: true`.
