# Движок

Браузерная 3D-игра без сборщиков и сети: `three.js r147` (глобальный `THREE`) + неблоковые `<script>`. Собранная игра — папка `games/<slug>/` с относительными путями: открывается двойным щелчком (file://), с флешки, с любого статического сервера и в `<iframe>` чужой страницы.

| файл | что |
|---|---|
| `engine/template.html` | страница; `{{…}}` подставляет `tools/build.js` из `meta` |
| `engine/css/game.css` | интерфейс |
| `engine/js/logic.js` | правила: слова, страницы, просьбы, замки, главная задача, проверка ответов, сумка/лавки/поручения (`inv`, `buy`, `refund`, `takeErrand`, `deliver`, `npcDelivery`). Без DOM — его же гоняет `validate` |
| `engine/js/layout.js` | геометрия мира без three.js: раскладка зон, точки, площади, расстояния. Общая для движка и `validate` (утверждения о сцене) |
| `engine/js/world.js` | 3D: загрузка моделей, построение мира из `QUEST.world`, герой (WASD, клик-идти, бег), A* и коллизии, двери/калитки/интерьеры, таблички, жители (анимации, предмет в руке), камера, время суток, погода, финал |
| `engine/js/ui.js` | интерфейс: реплики, тултипы, догадка у слова, дневник, незнакомые слова, повторение перетаскиванием, просьбы с греческой клавиатурой, подсказка/сдаться, черновики, главная задача, **сумка слева** (деньги и предметы с тултипами), **лавка торговца** (кнопка «Купить» в разговоре: товары только по-гречески с ценами, количество, «вернуть 1» — деньги назад), **поручения** (взять деньги/предмет → купить → принести; отдача сама при разговоре), голоса, сохранение |
| `engine/js/art.js` | 2D: пиктограммы (`window.PICTOS`), портреты жителей (`npcs[].looks`), картинки просьб |
| `engine/js/sound.js` | звуки интерфейса (WebAudio, без фоновой музыки) и озвучка `speechSynthesis` el-GR, голос по полу жителя |
| `engine/lib/` | three.min.js, GLTFLoader.js |

## Сборка
`node tools/build.js <slug>` → `games/<slug>/`:
- `data/models.js` — только используемые модели (base64) и текстуры наборов;
- `data/pictos.js` — используемые пиктограммы;
- `data/quest.js` — `var QUEST = …` без `claims`; ответы пропусков, перевод и ответ главной задачи зашифрованы (`~base64(xor)` с `meta.saveKey`), расшифровка — `dec()` в logic.js;
- `licenses/` — лицензии three.js и наборов Kenney (CC0) + CREDITS.txt.

## Управление
WASD/стрелки, Shift — бег (клик далеко — бег сам), клик по земле — идти, клик по жителю/табличке — подойти; **E / F / пробел — говорить; E — закрыть табличку, лавку, просьбу, дневник, окно догадки (кроме ввода текста)**, колесо — зум. **Камеру игрок не крутит**: в каждой локации свой постоянный ракурс (`zone.camera`), между локациями (зоны-подложки `nav:false` и `camera:"free"`) камера плавно поворачивается туда, куда идёт герой; на выходе из здания камера всегда фиксирована (снаружи, лицом к фасаду; `door.camera` переопределяет), пока герой не отойдёт от двери на 5 м; при смене ракурса направление «вперёд» держится, пока игрок не отпустит клавиши, J — дневник, Esc — закрыть.

## Метки над жителями
«?» — есть просьба, но слова ещё не разгаданы; «!» — просьбу можно выполнить / поручение можно сдать; голубая «…» — у жителя есть реплики, которые ученик ещё не слышал (`npcUnread` в `logic.js`, по `state.heard`). Если есть и просьба, и неуслышанные реплики — красная точка на «?» / «!». Метка гаснет, когда все доступные сейчас реплики услышаны, и загорается снова, когда сюжет открывает новые (`req` / `until` / `reqMystery`). Жители в закрытых зонах не помечаются.

## Отладка
`window.WORLD.debug` (hero, place, spawn, goTo, click, reach — проходимость до жителей/табличек/дверей), `window.__G` (состояние, открыть окна), `WORLD.stats()`.

## Расширение
- Новый процедурный предмет — функция в world.js + ветка в `addProp` + строка в таблице `docs/content-schema.md` + enum `p` в схеме.
- Новые модели — `assets/kenney/<kit>/` (только CC0 с kenney.nl) → `node tools/catalog.js`.
- Новая пиктограмма — `assets/pictos/<id>.svg` (общая) или `quests/<slug>/pictos/<id>.svg`.
