# Чего не хватает для типичных слов A1

Всё — только с официального kenney.nl (CC0). Скачать: `bash _downloads/fetch-kenney.sh <набор>`, распаковать, скопировать `Models/GLB format/*.glb` и `colormap.png` в `assets/kenney/<kit>/`, `node tools/catalog.js`.

| тема A1 | чего нет | где взять у Kenney | пока обходимся |
|---|---|---|---|
| животные (σκύλος, γάτα, άλογο, πουλί) | анимированные животные | **Cube Pets**, **Animal Pack** (3D) | процедурные `dog`, `cat` в движке |
| одежда, цвета (πουκάμισο, κόκκινο) | вешалки, одежда на прилавке | **Clothing** нет в 3D; **Mini Characters** — цвета одежды | ткани/ящики (`box` цветом), пиктограммы |
| школа, класс (τάξη, πίνακας) | доска, парты | **Furniture Kit** (есть desk), **School Kit** нет | `box`-доска + desk |
| больница, аптека (γιατρός, φάρμακο) | кровать-каталка, аптечка | **Furniture Kit** (bed), **Survival Kit** (medkit?) | furn/bed + крест-табличка |
| погода (βροχή, χιόνι, ήλιος) | — | движок: `env.weather` rain/snow | есть |
| транспорт (λεωφορείο, ταξί, τρένο, πλοίο, αεροπλάνο) | самолёт | **Space Kit**? нет; **Plane** — нет 3D у Kenney | car/train/boat есть; самолёт — только пиктограммой |
| горы, деревня (βουνό, χωριό) | крупные скалы, домики-шале | **Nature Kit** (cliff_*), **Fantasy Town Kit** | есть |
| спорт, игры (μπάλα, ποδήλατο) | мяч, велосипед | **Sports Pack**? (2D), **Car Kit** нет велосипеда | `cyl`/шар, пиктограмма |
| музыка (κιθάρα, πιάνο) | инструменты | нет 3D | процедурная `violin`; пианино — `box` |
| семья (μαμά, μωρό) | дети, младенцы | Mini Characters — только взрослые | масштаб `h` поменьше у персонажа |

Если слово «зрительное» (`claimKind`), а модели нет — сделайте процедурный предмет в движке (см. docs/engine.md «Расширение»), а не обходитесь табличкой.
